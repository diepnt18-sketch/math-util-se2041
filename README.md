
## Project Description
Math Util SE2041 is a Java project that provides mathematical utility methods.

## Unit Testing
This project uses JUnit to test mathematical functions and verify that the methods work correctly.

## Test-Driven Development (TDD)
Test-Driven Development is a software development approach in which tests are written before the implementation code.
